# 📝 Todo App

A simple and responsive **Todo App** built with React that helps users easily add, manage, complete, and delete their daily tasks using **Redux** 

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 Manage todo items easily
- 🔄 Update taks easily
- 🗑️ Delete tasks easily
- 📱 Responsive design
- 🎨 Clean and simple UI



## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
